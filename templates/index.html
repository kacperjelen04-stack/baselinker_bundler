Ustawienia

Jak to działa?

  1. Uzupełnij token API i ID katalogu powyżej.
  2. Przeciągnij plik CSV z zestawami (albo go wybierz klikając).
  3. Sprawdź podgląd pierwszych 5 wierszy — kolumny muszą się zgadzać.
  4. Kliknij „Rozpocznij tworzenie zestawów”.
  5. Obserwuj log na żywo. Gotowe zestawy pojawią się w katalogu BaseLinker.

Pliki XML

Profil hurtowni

Profile trzymane są tylko w tej przeglądarce (localStorage), nie na serwerze.

Jak to działa?

  1. Wgraj jeden lub dwa pliki XML od hurtowni i kliknij „Wczytaj i wykryj pola”.
  2. Program sam znajduje powtarzalne pola (nazwę, cenę, EAN, cechy...) i pokazuje przykładowe wartości.
  3. Dla każdego wykrytego pola wybierz, na jaką kolumnę CSV ma trafić (albo „pomiń”).
  4. Kliknij „Generuj CSV” — plik pobierze się od razu.
  5. Zapisz mapowanie jako profil, żeby przy kolejnej ofercie tej samej hurtowni nie robić tego od nowa.
